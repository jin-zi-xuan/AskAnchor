# AskAnchor · 问猫 🐈‍⬛

哪里没懂，问猫一下。

我做了一只住在 AI 聊天框旁的小黑猫。读回答时，选中没看懂的那句话就能继续追问。问完绕远了，点点小猫，再回来看原文。

AskAnchor，问锚，也叫「问猫」。

## 怎么用

1. **圈一句**：选中 AI 回答里的文字，点击「追问这一段」。
2. **问一下**：选个问法，问题会填进当前输入框。确认发送后，小猫就记下这处锚点。
3. **回来读**：点小猫，找到刚才的锚点，跳回原文接着看。

可以让 AI 解释概念、举个例子、换种说法，也能翻译、分析代码，或检查这段话有没有问题。

小猫负责记路，回答还是交给你正在用的 AI。

## 小猫的日常

- 点一下，翻翻记下的锚点。
- 拖一拖，换个舒服的位置。
- 双击，先躲到旁边。
- 偶尔眨眨眼，动动耳朵，陪你读会儿。

锚点可以改名、删除，也能标记「未解决 / 已理解」。每个对话单独保存，最多留下 50 个。

旁边还有一条对话时间轴，方便翻回之前的问题。

## 能在哪儿用

ChatGPT、Gemini、Claude、Perplexity、Poe、Copilot、DeepSeek、Kimi、豆包、通义千问和文心一言。

各家页面经常变化，适配可能偶尔掉队。原句暂时找不到时，小猫会留下保存的原文卡片，不让这句话一起丢了。

## 领一只回去

以 Chrome 为例：

1. [下载问猫测试版](https://github.com/jin-zi-xuan/AskAnchor/releases/tag/v0.2.1)，选择 `AskAnchor-0.2.1-chromium.zip` 并解压。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 打开支持的 AI 网站；已经打开的页面刷新一下，小猫就来了。

Edge 的安装方法相同，扩展管理页是 `edge://extensions`。安装包不用编译，也不用安装 Node.js。

目前已在 macOS 的 Chrome、Edge 上完成核心流程回归测试。Windows 同浏览器版本待实测；Firefox 和 Safari 暂不支持此安装包。

更新插件后，记得在扩展管理页重新加载，再刷新聊天页面。

不想显示小猫，或只想在部分网站使用，可以到设置里调整。

## 关于你的聊天

不需要 API Key，也不用注册新账号。

问猫没有后端，不会把聊天记录上传给我。锚点保存在你的浏览器里，追问由你确认后，发送给当前使用的 AI。
